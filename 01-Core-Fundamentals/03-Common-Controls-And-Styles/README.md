# 03. Common Controls & Styling (Базові елементи керування та стилізація)

### Що це?
У .NET MAUI елементи керування транслюються у відповідні нативні віджети кожної платформи (Android EditText/Button, Windows TextBox/Button). Стилізація виконується через XAML `ResourceDictionary` та систему каскадних стилів (`Style`, `Setter`).

### Ключові елементи:
- Введення тексту: `Entry` (однорядковий), `Editor` (багаторядковий), `SearchBar`.
- Вибір значень: `CheckBox`, `Switch`, `Slider`, `Stepper`, `DatePicker`, `TimePicker`.
- Візуалізація: `ProgressBar`, `ActivityIndicator`, `Image`, `BoxView`.
