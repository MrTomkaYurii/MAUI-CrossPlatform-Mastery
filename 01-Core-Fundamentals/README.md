# Модуль 01: Основи .NET MAUI та Архітектура (Core Fundamentals)

Цей модуль містить фундаментальні основи побудови кросплатформених застосунків:
1. **01.Maui.StartupLifecycle** — точка входу, конфігурація `MauiAppBuilder`, Dependency Injection, структура `App.xaml` та `AppShell.xaml`.
2. **02.Maui.LayoutsDeepDive** — вичерпне порівняння контейнерів `Grid`, `VerticalStackLayout`, `HorizontalStackLayout`, `FlexLayout`, `AbsoluteLayout`.
3. **03.Maui.CommonControlsAndStyles** — огляд віджетів користувацького інтерфейсу, організація глобальних та локальних стилів, робота з палітрами.
