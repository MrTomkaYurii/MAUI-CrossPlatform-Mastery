# 04. Data Binding Modes & StringFormat (Режими прив'язки даних)

### Що це?
Механізм Data Binding з'єднує інтерфейс користувача (XAML) із бізнес-логікою (C# ViewModel). Режим зв'язування (`BindingMode`) визначає напрямок потоку даних.

### Режими Binding:
1. **`OneWay`** (за замовчуванням для більшості властивостей): дані передаються від ViewModel до UI.
2. **`TwoWay`** (за замовчуванням для полів вводу `Entry.Text`, `CheckBox.IsChecked`): зміна у формі оновлює поле ViewModel, а оновлення в коді оновлює поле в UI.
3. **`OneWayToSource`**: зворотній потік (UI → ViewModel).
4. **`OneTime`**: одноразова ініціалізація при побудові дерева без відстеження оновлень (економить пам'ять).
