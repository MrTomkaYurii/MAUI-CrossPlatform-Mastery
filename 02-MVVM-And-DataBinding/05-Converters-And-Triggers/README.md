# 05. Converters & Triggers (Конвертери значень та тригери в XAML)

### Що це?
- **Value Converters (`IValueConverter`)** перетворюють дані між типами, якщо модель має один тип (наприклад `bool` або `int`), а UI очікує інший (наприклад `Color` або форматований текст).
- **Triggers** дозволяють декларативно у XAML змінювати зовнішній вигляд елементів при зміні властивостей, подій або станів без написання процедурного коду.

### Види тригерів:
- `PropertyTrigger`: реагує на властивість поточного елемента (наприклад `IsFocused == true`).
- `DataTrigger`: реагує на прив'язану властивість з ViewModel (`IsBusy == true`).
- `EventTrigger`: спрацьовує при виникненні UI події (наприклад `Clicked`, `Appearing`).
- `StateTrigger`: активує потрібний `VisualState` на основі адаптивних умов.
