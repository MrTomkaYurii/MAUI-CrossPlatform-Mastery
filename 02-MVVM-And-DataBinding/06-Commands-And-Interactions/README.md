# 06. Commands & Interactions (Команди та взаємодія)

### Що це?
Патерн `ICommand` дозволяє відв'язати дію користувача у візуальному шарі (натискання кнопки, жест свайпу) від коду обробника, передаючи виконання безпосередньо у ViewModel без коду в `code-behind`.

### Асинхронні команди:
Звичайний `RelayCommand` приймає синхронний `Action`. Для взаємодії з мережею чи БД використовується `AsyncRelayCommand`, який автоматично блокує повторні натискання (`CanExecute = false`) під час виконання асинхронного таску.
