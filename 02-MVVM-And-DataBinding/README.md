# Модуль 02: MVVM та Data Binding (MVVM & Reactive UI)

У цьому модулі розглядаються всі тонкощі патерну Model-View-ViewModel:
- **04.DataBindingModes** — напрямки передачі даних, форматування рядків, fallback значення.
- **05.ConvertersAndTriggers** — створення кастомних конвертерів та керування UI через тригери.
- **06.CommandsAndInteractions** — кастомні `ICommand`, `RelayCommand` та асинхронні патерни.
- **07.CommunityToolkitMvvm** — використання офіційного тулкіту від Microsoft із C# генераторами коду.
