# 09. Navigation Hierarchy & Modal Pages (Ієрархія та модальні сторінки)

### Що це?
У MAUI розрізняють два типи переходу між екранами:
- **Ієрархічний стек (PushAsync/PopAsync)**: класичний перехід "вперед-назад" зі стрілкою повернення в заголовку.
- **Модальний стек (PushModalAsync/PopModalAsync)**: перекриває поточний екран для фокусу користувача на окремій задачі (наприклад, введення PIN-коду, оплата або авторизація).
