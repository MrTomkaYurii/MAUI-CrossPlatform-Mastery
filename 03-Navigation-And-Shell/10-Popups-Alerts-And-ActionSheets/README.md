# 10. Popups, Alerts & ActionSheets (Спливаючі вікна та діалоги)

### Що це?
Користувацькі діалоги в MAUI адаптуються під системні гайдлайни:
- `DisplayAlert`: інформаційні вікна або запити підтвердження "Так/Ні".
- `DisplayActionSheet`: вибір опцій зі списку (меню дій).
- `DisplayPromptAsync`: спливаючий інпут для швидкого введення рядка.
