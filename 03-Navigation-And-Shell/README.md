# Модуль 03: Навігація та Архітектура додатків (Navigation & Shell)

Цей модуль присвячено побудові багатоекранних застосунків:
- **08.ShellRouting** — URI маршрутизація, параметри запитів, вкладки TabBar та бічне меню Flyout.
- **09.NavigationHierarchy** — ієрархічний стек, стек модальних сторінок, переходи між сторінками.
- **10.PopupsAndDialogs** — системні алерти, вибір дій в ActionSheet, діалогові вікна.
