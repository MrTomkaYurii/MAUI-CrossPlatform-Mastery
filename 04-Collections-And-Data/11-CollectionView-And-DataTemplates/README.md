# 11. CollectionView & DataTemplates (Віртуалізація списків та шаблони)

### Що це?
`CollectionView` — це сучасний, високопродуктивний контейнер списків, що замінив застарілий `ListView`.
- **Повна віртуалізація**: елементи створюються лише тоді, коли потрапляють у зону видимості екрана.
- **Підтримка сіток**: `GridItemsLayout` дозволяє робити списки у 2, 3 або більше колонок.
- **Шаблонізація**: `DataTemplateSelector` динамічно вибирає дизайн картки (наприклад, окремий вигляд для звичайних новин і Featured новин).
