# 13. SQLite Local Database (Локальне сховище на SQLite)

### Що це?
`sqlite-net-pcl` — стандарт де-факто для локального реляційного збереження даних на Android, iOS, Windows та macOS.
- Повністю асинхронний доступ (`SQLiteAsyncConnection`).
- Маппінг сутностей через C# атрибути (`[PrimaryKey]`, `[AutoIncrement]`, `[Table]`).
- Незалежність від зовнішніх серверів — працює офлайн на 100%.
