# Модуль 04: Списки, Колекції та Віртуалізація (Collections & Data)

Модуль покриває роботу з великими обсягами даних у UI:
- **11.CollectionViewVirtualization** — віртуалізація рядків, сітки елементів, селектори шаблонів.
- **12.InfiniteScrollRefresh** — інтеграція `RefreshView`, динамічне пагінування.
- **13.SQLiteDatabase** — створення таблиць, CRUD операції, патерн репозиторію для мобільних додатків.
