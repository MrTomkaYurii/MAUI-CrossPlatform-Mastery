# 14. Device Sensors & Connectivity (Сенсори та статус мережі)

### Що це?
.NET MAUI об'єднує системні датчики під спільним уніфікованим API:
- `Connectivity.Current.NetworkAccess`: відстеження наявності інтернету в реальному часі.
- `Battery.Default`: рівень заряду та режим енергозбереження.
- `Geolocation.Default`: координати GPS, компас та акселерометр.
