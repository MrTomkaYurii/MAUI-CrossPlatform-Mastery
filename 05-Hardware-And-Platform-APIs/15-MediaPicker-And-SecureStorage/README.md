# 15. MediaPicker & SecureStorage (Мультимедіа та безпечне сховище)

### Що це?
- `SecureStorage`: зберігання JWT токенів та паролів у системних нативних захищених сховищах (Android KeyStore, iOS Keychain, Windows Credential Manager).
- `MediaPicker`: доступ до нативної фотокамери та галереї з автоматичним запитом дозволів (`Permissions`).
