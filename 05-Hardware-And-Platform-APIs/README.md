# Модуль 05: Платформо-специфічні фічі та пристрої (Hardware & Platform APIs)

Цей модуль демонструє роботу з апаратними можливостями пристроїв:
- **14.DeviceSensors** — геопозиція, стан батареї, статус підключення до мережі.
- **15.MediaAndFileSystem** — камера, галерея, нативне шифроване сховище `SecureStorage`.
- **16.PlatformHandlers** — сучасна архітектура маппінгу контролів на нативні віджети ОС.
