# 17. GraphicsView & Microsoft.Maui.Graphics (Графічне малювання та Canvas)

### Що це?
`Microsoft.Maui.Graphics` — це кросплатформена бібліотека векторного малювання:
- Малювання нативних векторних примітивів (кола, полігони, криві Безьє).
- Побудова власних віджетів, графіків, індикаторів прогресу без сторонніх бібліотек.
- Висока продуктивність через Direct2D на Windows, Skia/Metal на macOS/iOS та Android Canvas.
