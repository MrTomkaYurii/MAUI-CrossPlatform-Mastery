# 18. Animations & VisualStateManager (Анімації та менеджери станів)

### Що це?
- `ViewExtensions`: базові плавні анімації (`ScaleTo`, `FadeTo`, `TranslateTo`, `RotateTo`).
- `VisualStateManager (VSM)`: дозволяє пов'язати зовнішній вигляд елемента з його станом (Normal, Pressed, Disabled, PointerOver) прямо в XAML.
