# 19. Dynamic Theming (Динамічні теми: Світла, Темна, Системна)

### Що це?
`AppThemeBinding` дозволяє автоматично перемикати кольори та стилі при зміні системного режиму смартфона або перемикати тему в налаштуваннях програми в рантаймі:
```xml
<Label Text="Вітаємо" TextColor="{AppThemeBinding Light=#111827, Dark=#F9FAFB}" />
```
