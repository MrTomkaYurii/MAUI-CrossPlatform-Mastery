# 20. .NET MAUI Blazor Hybrid (Гібридні застосунки)

### Що це?
`BlazorWebView` дозволяє інтегрувати веб-компоненти Razor усередину нативного MAUI вікна:
- **100% спільний код** між вебом (Blazor WebAssembly/Server) та мобільними застосунками.
- Виконання коду C# безпосередньо на пристрої (без WebAssembly емуляції).
- Повний доступ до нативних API пристрою (камера, сенсори) прямо з Razor компонентів через DI!
